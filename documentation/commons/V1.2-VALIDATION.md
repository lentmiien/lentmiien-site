# Lantern Commons v1.2 validation

Validation date: 2026-10-09, development feature branch. All data used below is
synthetic. No production database, configured Site environment, physical device,
external AI provider, deployment or merge was exercised. The art generation call was
separate from application testing; its prompt/provenance is in [ART-V1.2.json](ART-V1.2.json).

## Automated checks

- Focused Commons plus My Page task completion, dashboard parity and private admin
  database-viewer checks: **13 suites / 161 tests passed**. This included the real
  isolated Mongo suite described below.
- Full `npm test -- --runInBand`, including repository coverage thresholds:
  **375 suites passed, 7 skipped; 4,730 tests passed, 110 skipped** (184.19 seconds).
- Final transport review: **10 tests passed**, including the added error-redaction
  regression and task completion after fresh authorization. The full run above was
  repeated after these last changes and includes that additional test.
- Syntax: all **35 changed/new JavaScript files** passed `node --check`.
  `views/commons.pug` compiled with the installed Pug compiler. `git diff --check`
  passed. No curated OpenAPI YAML or dependencies changed. This repository has no
  general JavaScript lint script; no nonexistent lint pass is claimed.

The full run passed with existing experimental VM modules warnings, Mongoose's
`new` option deprecation in existing code and an existing Promise-like middleware
warning. These were not test failures and were not hidden by changing unrelated code.
The 110 skipped tests are the suite's existing skips; v1.2 Mongo tests ran explicitly.

## Actual Mongo verification

An already available MongoDB 8.0 Docker image ran in a disposable, loopback-only
container, with a tmpfs database directory and no host configuration or data mounts.
`COMMONS_TEST_MONGO_URL` selected only a `commons_test_*` database. The opt-in test
rejects URLs outside `mongodb://127.0.0.1:<port>/commons_test_<safe suffix>`.
Tests drop only their guarded synthetic database. The container is removed afterward.

`tests/unit/commons/mongo.test.js` verifies actual model registration/BSON ObjectId
casting, the owner/date unique index, concurrent create/edit compare-and-set,
20-date history pagination, literal text storage, and Mongo `$$NOW` Tokyo-date guard
aborting both insert and update when the application clock proposes the wrong date.
It also checks canonical task completion races/foreign and ownerless denial/deletion,
the five real selected collection counts, and the unchanged single-worker Mongo lease
with `lantern-commons-v1` persistence and safe restricted-room restoration.

These are real local database operations. The browser harness below intentionally uses
in-memory model adapters; it is not an end-to-end browser-to-Mongo or production test.

## HTTP/session/socket/browser verification

[scripts/review-commons-v12.js](../../scripts/review-commons-v12.js) launches the isolated
Express/session/Socket.IO preview with synthetic task/stock/stat/diary fixtures. It uses
the real Commons router, authorization, CSRF, socket transport, panels, simulation and
Canvas renderer. Fixture positioning places residents near interactions; the browser
then clicks/touches the actual UI. Reachability is separately tested with walkable
paths from each scene's spawn to every interaction and exit.

**31 new browser checks passed**, with no browser JavaScript errors:

- Quest flip, report-as-done and immediate board reconciliation on desktop and touch,
  including a second account's independent tasks.
- Hall entry, both shelves, aggregate source/freshness presentation and safe exit;
  touch opens the authorized shelf too.
- Family Shelter touch entry and canonical person-meals/litres/equipment display;
  an unrelated admin is denied.
- Diary explicit save, inert markup text, read-only history, concurrent revision conflict
  with separately retained draft, and another admin's isolated diary.
- Desktop village zoom in/out, daylight/night at DPR 2; mobile portrait and landscape,
  daylight/night, reduced-motion preference, DPR 2 and zoom controls without horizontal
  overflow. Interiors intentionally fit to screen rather than using village zoom.
- Role revocation ejects to the public exit and purges the sensitive panel.

**19 existing browser regression checks passed** with no JavaScript errors:
keyboard/touch movement, release expiry, orientation/DPR, two accounts, duplicate-tab
takeover, delayed old disconnect, reconnect restoration, garden persistence, own-cottage
entry, scripted NPC fallback, revoked session, persistence failure and missing-art
recovery. The deliberate save-failure fixture produced the expected redacted
`commons.persistence` error; that is evidence of failure handling, not a live incident.

Machine-readable evidence:
[new workflows](validation-v1.2/browser-results.json) and
[existing regression](validation-v1.2/regression/browser-results.json).
Reproduction uses the existing preview scripts with Playwright supplied by the local
