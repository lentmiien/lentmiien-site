# Generated graphics

These WebP assets were generated with the built-in image generation tool and optimized for this browser game. The original generated PNGs are kept in Codex's generated-images directory.

| Asset | Use | Prompt |
| --- | --- | --- |
| `terrain-atlas.webp` | Eight map terrain tiles in a 4 × 2 atlas | Top-down hand-painted pixel-art-inspired terrain atlas: ocean, grassland, plains, forest, hills, mountains, desert, tundra; seamless square cells, no text or objects. |
| `unit-atlas.webp` | Eight representative unit emblems in a 4 × 2 atlas | Pixel-art-inspired unit silhouettes on dark navy: settler, infantry, archer, cavalry, siege cannon, sailing ship, airplane, mech; equal square cells, no text. |
| `world-dawn.webp` | New-game and dialog background | Panoramic dawn over an ancient world with stone cities, fields, river, mountains, and distant ships; atmospheric pixel-art-inspired illustration with room for a dialog; no text. |

The renderer falls back to its original canvas shapes and colors if an atlas cannot load.
