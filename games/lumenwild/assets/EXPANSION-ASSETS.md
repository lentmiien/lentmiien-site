# Beyond the Fold: generated artwork

Created using the imagegen skill and the built-in image generation tool. The original source PNGs remain in the generation output directory. These committed WebP assets are mechanical grid extractions and resizes, with alpha preserved for creatures and props.

- `tile-16..31`: marsh, orchard, and clockwork terrain (four columns by four rows).
- `tile-32..47`: frostglass, caldera, and astral terrain (four columns by four rows).
- `enemy-12..23`: tideglass crab, copperleaf mantis, clockwork scarab; four poses each.
- `enemy-24..35`: frostglass owl, ember salamander, astral moth; four poses each.
- `prop-16..47`: 27 regional relics and five exploration landmarks.
- `journey-atlas.webp`: illustrated nine-region world map.

Transparent sprites use a 192 × 192 WebP canvas. Terrain uses 192 × 192 WebP tiles. The atlas is 1536 pixels wide. No original assets were replaced.
