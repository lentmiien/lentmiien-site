# Original assets and provenance

All game-specific art is original procedural work written for Emberwake Isles. No Minecraft textures, characters, sounds or branding are copied. The imagegen skill was inspected; its guidance explicitly prefers code-native assets where those are the better fit. No AI raster generation or external image request was performed or is claimed.

Reproduce the committed assets from the repository root:

```sh
node games/emberwake-isles/scripts/generate-assets.cjs
```

- `atlas.png`: original 128×304 pixel atlas, 16×16 tiles, deterministic material noise, wood grain, masonry and mineral seam motifs. Generated with Node's built-in zlib plus a minimal deterministic PNG writer; no image library or network required.
- `icons/*.svg`: 197 original item illustrations, with dedicated tools, weapons, foods and vessels plus isometric material/furnishing swatches. Text labels disambiguate furniture; the shapes and palettes are shared where appropriate.
- `chart.svg`: original finite-island cartographic cover. The actual in-game map is generated from the same seeded terrain plus player edits as the simulation, not this stylized cover.
- `js/mesher.js`: authored box silhouettes for workstations, chairs, daybeds, canopy, sofa, lamps, windows, garden furniture, instruments and other furnishings; emitted into shared chunk geometry.
- `js/world.js`: procedural terrain, tree shapes, cave networks, and eleven original landmark sculptures, including listening shell, post office, teapot, quiet bell, moon moth archive, wind organ and patient apiary.
- `js/renderer.js`: procedural ocean, cloud boxes, celestial disc, atmospheric silhouettes, vessels, crops and five regional creature models.
- `js/audio.js`: original gesture-enabled synthesized gathering, placing, crafting, music-box and storm tones. No recordings or narration; no Piper use.
- `css/color-theme.css`: local copy of the existing Graphite/Ember/Golden Amber theme from Rocket Lander. The rest of the UI is new.
- `vendor/`: separately licensed, unmodified Three.js. See its MIT license and provenance.

The asset script and geometry/audio source are the reproducible source of truth. No generated art is referenced from an external tool cache or remote host.

Outer Gardens retains the original material tile indices and expands the atlas height from 128 to 176 pixels. UV dimensions come from `data.atlas`; new material IDs append after the original 62. The new 31 icons and two island drawings are regenerated by the same local tool. No image-generation service was used for this update.

Spectrum Shores expands the local atlas to 128×256, adds 45 generated item icons for 170 total, and updates the cover chart. The seven-stripe mosaic is drawn by the atlas generator. Island strata, sculptures and creature silhouettes come from the regional catalog, world generator and renderer.

The Tideglass portal adds one locally generated ring tile at voxel ID 126 and one matching SVG inventory icon, bringing the icon count to 171. Both are generated by the same asset script.


The floating islands append tiles 127–151 and 26 inventory illustrations. The 128×304 atlas includes authored patterns for mica, opal, basalt pipes, striped awnings, parquet and four-color marquetry. The SVG builder projects each new furnishing from its actual collision and rendering boxes. The sail mantle has a hand-authored vector illustration. The chart uses both island polygons and the lyre’s cutout. The local synthesizer plays an original five-note Nightjar carillon phrase. Rebuild all static illustrations with the command above.
