# Spectrum Shores verification

Run the model suite from the repository root with `node --test games/emberwake-isles/tests/*.test.cjs`. The 107 passing cases include all 105 recipe transactions, original cave physics and terrain fixtures, the frozen Outer Gardens voyage, and comparison of 1,849 old terrain chunks with their pre-expansion digest. Regional tests mine and place all twenty shades, read their map colors, collect pigment, shoo a creature and reload its state. The pack test fills both 12,000-item stacks and transfers a full 4,000-item chest. Fault injection exercises upgrade writes when a different older backup already exists. [Model output](models.txt)

Serve the module and use the Playwright and Chromium settings in [the update guide](../../../README-updates.md). Run `tests/browser-spectrum.cjs` with Node. The browser loads a synthetic v2 voyage. A separate voyage starts empty, builds and sails its own raft, upgrades tools, mines the Poppy quarry, crafts and places an inlaid brick, and restores it after a page reload. The automated controller uses the game's normal movement and action methods. It sailed 2,067 m, mined 86 blocks, placed eight and made one catch and one harvest. [Browser results and renderer samples](results.json)

The [chart](chart.png) shows the earned voyage. The island views and creature portraits use staged camera positions. The [rainbow arch](rainbow.png) was arranged as a visual fixture. Compare [Poppy](poppy.png), [Sundial](sundial.png), [Fernwheel](fern.png) and [Iris](iris.png). Their [crab](poppy-creature.png), [hopper](sundial-creature.png), [beetle](fern-creature.png) and [moth](iris-creature.png) portraits use the regular target HUD.

The original Chromium smoke scenario also passed 28 checks including real mouse capture, mining and placing, recipe buttons, saves, edit persistence, storm reload, explicit safe restore and WebGL fallback. The Outer Gardens browser regression passed twelve checks, including weaponless combat and observing a built island appear and disappear on both maps. [Browser regression results](browser-regressions.json)

Chromium used SwiftShader at 1280 × 800 for the Spectrum captures. Each scene settled at 81 render chunks, 117 cached data chunks and an empty mesh queue. Frame timing is a short software-renderer sample. No hardware GPU, mobile or long human play session was measured.
