# Security contract — Emberwake Isles

Planned standalone fully-public game. Anonymous principals; no machine principals, capabilities, account objects or admin override. Public immutable art/code; anonymous private-to-browser play state. All mutations are local JavaScript/localStorage operations, with no HTTP write endpoints or session data. CSRF is therefore inapplicable. No API, telemetry, external hosts, uploads, dynamic code, or backend integration. Existing static auto-discovery is the only legacy dependency. Assets may use the host's public static cache policy; saves never leave the browser except a user-initiated JSON download.

Import maximum 2 MB; allowlisted schema version, numeric bounds, item IDs, voxel IDs, chunk coordinates, counts, arrays and string lengths. Unknown keys are rejected. Saved text is rendered with textContent only. No saved URLs or markup. Fixed local asset paths. Bounded chunks, physics steps, ray reach, recipe batch counts, entities and edit count. No secrets or private files are read. Errors appear in the local UI; there is no server operation requiring production logger changes.

Retention: three numbered local slots with primary, previous valid backup, and terminal voyage marker per slot. No unrelated localStorage keys are accessed or removed. Explicit slot overwrite/recovery actions only. Export for durable backup; browser clearing can lose saves. Storage failure never reports success; crossing cannot begin a terminal voyage without first journaling its marker, or the game stops at the warning boundary with an explicit persistence error. After a crash/reload the marker wins over an older safe state until the user explicitly restores a checkpoint or starts a new slot voyage. No offline simulation.

Negative tests cover malformed/oversized JSON, unknown schema/IDs/keys, invalid coordinates/counts, quota and denied access, backup preservation, primary corruption, terminal reload, body collision and interaction reach. No deployment, environment changes, routing changes or database migrations.
